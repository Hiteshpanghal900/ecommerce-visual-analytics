# E-Commerce Visual Analytics

**Data Visualization Design — IIT Madras**

A data visualization project studying the complete e-commerce customer journey — from order placement and seller handling to delivery and customer reviews.

The goal is to understand **what drives customer satisfaction, where delivery and seller performance create risk, and how the marketplace can grow without compromising customer experience.**

## 🎯 Project Objective

This project aims to answer questions such as:

* Which product categories have the highest customer satisfaction or dissatisfaction?
* How does delivery performance affect customer review scores?
* Which seller behaviors are associated with poor customer experiences?
* Are there regional patterns in delivery delays and customer satisfaction?
* Which segments represent the greatest business risk?
* Where should the marketplace intervene while continuing to support growth?

## 📊 Dataset

The primary dataset is the **Brazilian E-Commerce Public Dataset by Olist**, containing information about:

* Orders
* Customers
* Sellers
* Products
* Payments
* Delivery
* Customer reviews

The **Marketing Funnel** dataset may also be incorporated to analyze customer acquisition and conversion.
